# KO’AKE Event Photo v1.4.2

เว็บขายภาพกิจกรรมสำหรับช่างภาพ ลูกค้าค้นหาและเลือกภาพ ระบบคิดราคาตามจำนวน แสดง QR พร้อมเพย์ตามยอด รับสลิปแบบ private และเปิดดาวน์โหลดไฟล์เต็มเมื่อแอดมินอนุมัติ

## ขั้นตอนของลูกค้า

1. เปิดลิงก์อัลบั้มและเลือก 1–10 รูป
2. ระบบคำนวณราคาอัตโนมัติ
3. สร้างคำสั่งซื้อและสแกน QR พร้อมเพย์
4. อัปโหลดสลิป JPG, PNG หรือ WebP ไม่เกิน 6 MB
5. รอช่างภาพตรวจสลิป
6. เมื่ออนุมัติแล้ว ดาวน์โหลดไฟล์ต้นฉบับแบบไม่มีลายน้ำได้ 7 วัน

## โครงสร้างระบบ

- Vercel: หน้าเว็บและ API
- Supabase: ฐานข้อมูลอัลบั้ม รูป ราคา ออเดอร์ และ Storage private สำหรับสลิป
- ImageKit: พรีวิวลายน้ำและไฟล์ต้นฉบับ private
- PromptPay: สร้าง QR แบบระบุยอดจาก `PROMPTPAY_ID`

API ถูกจัดรวมให้เหลือ 12 Vercel Functions เพื่อรองรับข้อจำกัดของแผน Hobby โดย URL เดิมยังใช้งานได้ผ่าน `vercel.json`

Migration ลำดับที่ 3 จะสร้าง bucket `payment-slips` แบบ private และจำกัดไฟล์ไม่เกิน 6 MB ส่วนลำดับที่ 4 เพิ่มการตรวจสถานะสลิปแบบ atomic และป้องกันการอนุมัติเมื่อไฟล์ต้นฉบับไม่พร้อม ลำดับที่ 5 แก้ปัญหา `function gen_random_bytes(integer) does not exist` ตอนกดสั่งซื้อ โดยเลิกพึ่งพา pgcrypto ในฟังก์ชันสร้างออเดอร์ ลำดับที่ 6 และ 7 เพิ่มคอลัมน์เก็บผลตรวจสลิปอัตโนมัติและลายนิ้วมือไฟล์สลิป ลำดับที่ 8 ทำให้ยอดเงินแต่ละออเดอร์มีเศษสตางค์แบบสุ่มไม่ซ้ำกัน (ดูหัวข้อถัดไป)

## กันสลิปซ้ำ (เปิดใช้งานอยู่แล้ว ฟรี ไม่ต้องสมัครอะไรเพิ่ม)

ทุกสลิปที่ลูกค้าอัปโหลดจะถูกคำนวณลายนิ้วมือไฟล์ (SHA-256) เก็บไว้ ถ้ามีคนเอาไฟล์ภาพสลิปเดิม (ไบต์เหมือนกันทุกประการ) ไปอัปโหลดกับคำสั่งซื้ออื่น ระบบจะปฏิเสธอัตโนมัติทันทีพร้อมบอกว่าเคยใช้กับคำสั่งซื้อไหนไปแล้ว วิธีนี้ไม่ตรวจว่ายอดเงินในสลิปตรงหรือไม่ (ต้องดูด้วยตาเหมือนเดิม) แต่กันการโกงแบบเอาสลิปเดิมมาใช้ซ้ำได้ฟรี 100%

## ยอดชำระมีเศษสตางค์สุ่มไม่ซ้ำกัน (เปิดใช้งานอยู่แล้ว ฟรี ไม่ต้องสมัครอะไรเพิ่ม)

เวลาสร้างคำสั่งซื้อ ระบบจะบวกเศษสตางค์แบบสุ่ม 1-99 สตางค์เข้าไปในราคาแพ็กเสมอ เช่น แพ็ก 3 รูปราคาตั้งไว้ 100 บาท ลูกค้าอาจต้องโอนจริง 100.12 บาท แต่ละออเดอร์จึงมียอดที่ไม่ซ้ำกันแทบทุกครั้ง ช่วยให้ช่างภาพจับคู่สลิปกับคำสั่งซื้อได้ง่ายและแม่นยำขึ้นตอนตรวจด้วยตา โดยไม่ต้องพึ่งบริการอ่านสลิปภายนอกและไม่มีค่าใช้จ่ายเพิ่ม หน้าชำระเงินของลูกค้าและตารางคำสั่งซื้อของแอดมินจะแสดงยอดแบบ 2 ตำแหน่งทศนิยมเสมอเพื่อให้เห็นเศษสตางค์นี้ชัดเจน ส่วนตารางราคาที่ตั้งไว้ (หน้าร้านและหลังบ้าน) ยังคงแสดงเป็นราคากลมตามปกติ

## ตรวจสลิปอัตโนมัติแล้วอนุมัติให้เลย ไม่ต้องกดเอง (ไม่บังคับ มีค่าใช้จ่ายเฉพาะถ้าใช้เกินโควตาฟรี)

ระบบใช้ [Slip2Go](https://connect.slip2go.com) (`SLIP2GO_SECRET_KEY`) ในการอ่านยอดเงินและบัญชีผู้รับจริงจากธนาคารที่อยู่เบื้องหลังสลิป (ไม่ใช่แค่ดูตัวเลขในรูป) ถ้าตรวจผ่านและยอดตรงกับที่ต้องชำระ **ระบบจะอนุมัติคำสั่งซื้อให้อัตโนมัติทันที ลูกค้าดาวน์โหลดไฟล์เต็มได้เลยโดยไม่ต้องรอแอดมินกดอนุมัติ** การกันสลิปซ้ำทำสองชั้น: ลายนิ้วมือไฟล์ภาพ (ฟรี ทำงานเสมอ) และเลขอ้างอิงธุรกรรมจริงจากธนาคาร (ผ่าน Slip2Go)

วิธีตั้งค่า: เข้าแดชบอร์ด Slip2Go → เมนู "สาขา" สร้างสาขาของร้าน → ผูกบัญชีพร้อมเพย์ (เบอร์เดียวกับ `PROMPTPAY_ID`) เข้ากับสาขานั้น → เมนู "API Connect" > "Authentication" คัดลอก Secret Key มาใส่ `SLIP2GO_SECRET_KEY`

ปัจจุบันระบบอนุมัติอัตโนมัติเฉพาะกรณีที่ตรวจผ่านชัดเจนและยอดตรงเท่านั้น ส่วนกรณีอื่น ๆ (ยอดไม่ตรง, ตรวจไม่ได้, API ไม่ตอบ) จะตกมาให้แอดมินตรวจด้วยตาเหมือนเดิมเสมอ เพื่อความปลอดภัยไว้ก่อน

ถ้าไม่ตั้งค่า SLIP2GO_SECRET_KEY ระบบจะข้ามการตรวจยอด/บัญชีไปเฉยๆ ทุกคำสั่งซื้อต้องรอแอดมินกดอนุมัติเองเหมือนเดิม (การกันสลิปซ้ำแบบฟรีด้วยลายนิ้วมือไฟล์ยังทำงานอยู่เสมอไม่ว่าจะตั้งค่า Slip2Go หรือไม่)

**ข้อควรระวัง**: การอนุมัติอัตโนมัตินี้พึ่งพาความแม่นยำของ Slip2Go แนะนำให้เข้าไปดูรายการคำสั่งซื้อในหน้าแอดมินเป็นระยะเพื่อสุ่มตรวจสอบ แม้ระบบจะอนุมัติให้อัตโนมัติแล้วก็ตาม

## รูปพรีวิวสวยตอนแชร์ลิงก์อัลบั้ม (เปิดใช้งานอยู่แล้ว ฟรี ไม่ต้องตั้งค่าเพิ่ม)

เวลาแปะลิงก์อัลบั้ม (`/?event=...`) ลง LINE หรือ Facebook แอปเหล่านี้จะดึงหน้าเว็บไปอ่านแบบไม่รันจาวาสคริปต์ ถ้าไม่ทำอะไรเพิ่มจะเห็นแค่โลโก้/ชื่อเว็บทั่วไป ระบบนี้จะสร้างหน้า HTML เฉพาะสำหรับลิงก์แชร์ ใส่ชื่องาน คำอธิบาย และรูปปกอัลบั้มนั้นเป็นรูปพรีวิวให้อัตโนมัติ โดยผู้ใช้จริงที่กดลิงก์ยังเข้าเว็บแอปตัวเดิมทุกอย่างปกติ ไม่ต้องสมัครบริการเพิ่มหรือเสียเงิน

## แจ้งเตือนเข้า Telegram ทันทีที่มีสลิปใหม่ (ไม่บังคับ ฟรี)

แทนที่จะต้องคอยเปิดหน้าแอดมินดูเองว่ามีคำสั่งซื้อใหม่หรือยัง ระบบส่งข้อความแจ้งเตือนเข้า Telegram ให้ทันทีที่ลูกค้าส่งสลิป (บอกเลขคำสั่งซื้อ ยอดเงิน และผลตรวจสลิปซ้ำถ้ามี) เลือกใช้ Telegram แทน LINE Notify เพราะ LINE Notify ปิดให้บริการไปแล้วในปี 2025 ส่วน LINE Messaging API ตัวใหม่ต้องสมัคร LINE Official Account และทำ webhook ถึงจะส่งข้อความหาตัวเองได้ ยุ่งยากเกินไปสำหรับใช้คนเดียว

วิธีเปิดใช้งาน (ฟรี ใช้เวลา ~2 นาที):

1. เปิดแชทกับ `@BotFather` ใน Telegram พิมพ์ `/newbot` แล้วตั้งชื่อบอทตามที่มันถาม จะได้ **Bot Token** กลับมา
2. เริ่มแชทกับบอทของคุณเอง (กดลิงก์ที่ BotFather ให้มา) พิมพ์ข้อความอะไรก็ได้ 1 ครั้งเพื่อเปิดแชท
3. เปิดเบราว์เซอร์ไปที่ `https://api.telegram.org/bot<BOT_TOKEN>/getUpdates` (แทน `<BOT_TOKEN>` ด้วยโทเคนจริง) จะเห็น `"chat":{"id": ตัวเลข ...}` นั่นคือ **Chat ID** ของคุณ
4. ตั้งค่า `TELEGRAM_BOT_TOKEN` และ `TELEGRAM_CHAT_ID` ใน Vercel แล้ว deploy ใหม่

ถ้าไม่ตั้งค่า ระบบจะข้ามการแจ้งเตือนไปเฉยๆ ไม่กระทบการทำงานส่วนอื่น
